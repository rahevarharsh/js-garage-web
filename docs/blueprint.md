# **App Name**: JS Garaje

## Core Features:

- Home Page: Display hero sliders with promotional content, featured service cards, and curated content sections to welcome and engage visitors.
- Shop/Product Pages: Showcase a product catalog with advanced filtering and detailed product pages. Each product has images, descriptions, and 'add to cart' options, for clear and direct product discovery.
- Services & Appointment Booking: Provide a comprehensive service listing with appointment booking feature that allows users to book and manage appointments.
- AI Powered Product Recommendations: Recommend a list of best selling product based on the user's browsing history.
- Blog: Publish informative content via an integrated blog section to draw repeat traffic and add value.
- Firestore Product Database: Manage product details including images, descriptions, and prices using Firestore.
- Admin Pages: Admin pages allows authorized personnel to oversee products, customer engagement, orders, and site content.
- E-commerce features: Implement shopping cart functionality, Stripe payment gateway integration and customer login via Firebase Auth.

## Style Guidelines:

- Primary color: Deep blue (#294B63), evoking trust, reliability, and automotive expertise.
- Background color: Light grey (#EAEAEA), provides a clean and neutral backdrop to ensure readability and focus on content.
- Accent color: Bright orange (#E57A44), injects energy and highlights interactive elements like buttons and links.
- Headline font: 'Space Grotesk' (sans-serif) for headlines and shorter texts; body font: 'Inter' (sans-serif) for body text.
- Use flat, modern icons with an outlined style to represent various services, products, and actions. Icons should consistently use the primary and accent colors to maintain visual cohesion.
- Adopt a grid-based layout to ensure content is well-organized and responsive across different devices. Prioritize clear visual hierarchy with ample whitespace to improve readability and user experience.
- Incorporate subtle transitions and animations for UI elements like hovers and loading screens. Use animations sparingly to guide users through the site smoothly.
